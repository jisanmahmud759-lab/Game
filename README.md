# ঢাকা রিকশা রান 🛺

A mobile-friendly Bengali arcade traffic game made by **Jisan Mahmud**.

## GitHub Pages setup
1. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the **root** of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then press **Save**.
5. Wait a minute or two, then open the Pages URL.

## Controls
- Move: `←` / `→` or `A` / `D`
- Speed: `↑` / `↓` or `W` / `S`
- Pause / resume: `P` or `Esc`
- Mobile: touch buttons or tap left/right side of the road
- Sound: tap the speaker icon

## Notes
- Works as a static GitHub Pages site; no build tools required.
- Sound and Bengali speech are browser/device dependent. Some devices may not have a Bengali speech voice installed.
- The game uses emoji artwork and drawn scenery, so no extra image assets are required.
